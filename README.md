# Construction QA Landing Page

A lightweight Next.js landing page designed for deployment on Vercel.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Deploy to Vercel

1. Push this folder to GitHub.
2. In Vercel, click **Add New → Project**.
3. Import the GitHub repo.
4. Vercel will detect Next.js automatically.
5. Click **Deploy**.

## Before launch

Search/replace `hello@example.com` in `app/page.tsx` with your actual email or replace the `mailto:` links with your signup/demo route.

You can also replace “Construction QA” with the final company/product name globally.
